# RoboCasa Environment Installation

For the WM4A dependency versions and separate environments, use
[the WM4A environment instructions](../../environment/README.md).

For a standalone RoboCasa installation, consult the
[RoboCasa installation instructions](https://github.com/robocasa/robocasa-gr1-tabletop-tasks?tab=readme-ov-file#getting-started).

Install the additional command-line dependency inside the RoboCasa environment:

```bash
pip install tyro
```
