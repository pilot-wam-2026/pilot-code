# RoboTwin Environment Installation

Install the base environment using the
[RoboTwin installation instructions](https://robotwin-platform.github.io/doc/usage/robotwin-install.html).

Activate the RoboTwin environment and run from this repository root:

```bash
pip install -r examples/Robotwin/eval_files/requirements.txt
```

Set `ROBOTWIN_PATH` in `examples/Robotwin/eval_files/eval.sh` to the
local RoboTwin installation directory.
